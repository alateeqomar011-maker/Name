# Primeval: The Lost Frontier

An open-world prehistoric survival & exploration game built with Three.js — everything (terrain, vegetation, dinosaurs, sound) is generated procedurally.

## Run
```
npm install
npm run dev     # http://localhost:5173
npm run build   # static build in dist/
```

## Features
- 4 km × 4 km seamless continent + islands: mountains, volcano, jungle, forests, grasslands, desert canyons, swamp, rivers, waterfalls, ocean, caves, ruins
- 19 procedurally modelled & animated species (T-Rex, Velociraptor, Triceratops, Spinosaurus, Brachiosaurus, Stegosaurus, Ankylosaurus, Parasaurolophus, Pteranodon, Mosasaurus, rare Giganotosaurus/Therizinosaurus/Quetzalcoatlus…) with herds, hunting, drinking, sleeping, fleeing and defensive AI
- First/third-person (V), walk/sprint/crouch/jump/climb/swim/glide; jeep, boat, gyrocopter
- Survival stats, crafting, base building with upgrades & defenses, XP/levels/skills/titles
- Day/night, regional dynamic weather (rain, storms with lightning, fog, snow, sandstorms), wet surfaces
- World events: eruptions, earthquakes, storms, migrations, rare encounters, floods, forest fires
- Fog-of-war map, field journal, photo mode with rated shots, 60+ missions and a main storyline

## Controls
WASD move · Shift sprint · Space jump/glide · C crouch · V camera · E interact (hold to gather) · F vehicle · P camera · B build · Tab pack/crafting · M map · J journal · N missions · K skills · G summon vehicle · T tracker · L headlamp · 1–5 hotbar · Esc pause
